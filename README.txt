Melt Cam 2022 - iPhone web app

The live camera needs the app to be opened from an https:// address.
Put the files in this folder online, for example:

  GitHub Pages: create a repository, upload every file in this folder,
  then Settings > Pages > Deploy from branch (main, root).
  Netlify Drop: drag this folder onto app.netlify.com/drop.

Then on your iPhone:
  1. Open the https:// address in Safari.
  2. Tap Share, then Add to Home Screen.
  3. Open Melt Cam from the Home Screen and tap Live camera. Allow camera access.

Snapshots and recordings open the share sheet: choose Save Image or Save Video.
Everything runs on the phone. Nothing is uploaded.
